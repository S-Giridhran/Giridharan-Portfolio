Hospital Operations & Patient Analytics Dashboard

Power BI Data Visualization Project

Project Overview

This Power BI dashboard provides comprehensive insights into hospital operations, patient admissions, treatment efficiency, and resource utilization. It helps hospital management identify bottlenecks, improve patient care, and optimize costs.

Tools Used

Power BI Desktop
Interactive Dashboard Creation
SQL
Data Extraction & Joins
Data Visualization
KPI Cards, Charts, Slicers
Excel
Data Cleaning & Preparation

Key Insights

  • • Certain conditions generate higher treatment costs.
  • • Increase in length of stay leads to higher cost.
  • • Some conditions have higher readmission rates.
  • • Majority of patients recover successfully.
  • •Patient satisfaction varies based on treatment type.
