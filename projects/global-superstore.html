Global Superstore Sales Performance Dashboard

Tableau Data Visualization Project

Project Overview

This project analyzes the Global Superstore sales data to uncover key business insights. Interactive Tableau dashboard was built with filters for Region, Category, Segment, Ship Mode and Year. The analysis helps identify top performing products, underperforming regions and sales trends.

Tools Used

Tableau Desktop
Interactive Dashboard Creation
SQL
Data Extraction & Joins
Data Visualization
Bar, Line, Map & KPI Charts
Excel
Data Cleaning & Preparation

Key Insights

  • • Technology category contributes the highest profit margin.
  • • West region performs significantly better than other regions.
  • • Consumer segment generates the highest sales volume.
  • • Discount offers have negative impact on overall profit.
