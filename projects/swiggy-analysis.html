Swiggy Sales Analysis Using MS SQL Server 22

SQL Project

Project Overview

Developed an end-to-end SQL data analytics project using Microsoft SQL Server to analyze retail sales data. The project includes database design, star schema implementation, data cleaning, validation, SQL querying, joins, CTEs, window functions, views, stored procedures, and business insight generation to support data-driven decision making.

Tools Used

Microsoft SQL Server
Database creation, management & data analysis
SSMS (SQL Server Management Studio)
Query execution & database management
SQL
Joins, CTEs, Window Functions & Aggregations
Star Schema Design
Fact & Dimension table modeling

Key Insights

  • • SQL analysis shows that certain restaurants consistently generate higher order volumes due to strong customer ratings and demand patterns.
  • • Peak order times are observed during evening hours, indicating high demand during dinner time compared to lunch and breakfast.
  • • Cuisine-wise analysis reveals that North Indian and Fast Food categories dominate total orders across the dataset.
  • • Location-based grouping highlights that metro areas contribute significantly higher order counts than non-metro regions.
  • • Customer rating trends indicate that highly rated restaurants tend to receive more repeat orders and better visibility.
